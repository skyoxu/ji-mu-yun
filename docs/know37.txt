这不是文档差异，是 production semantic mismatch。

P1-2：Runtime policy / conjunctive lease 还没有真正闭合

Architecture AD-10 固定：

lease_occupied =
  process_identity_matches
  AND liveness_not_expired
  AND effective_progress_window_not_expired
  AND no_terminal_event

并要求 runtime policy 独立拥有 liveness、progress/no-progress、grace、lease、retry、backoff、status throttle 等字段。

当前 runtime-policy.v1.json 实际只有：

{
  "no_progress_seconds": 3600,
  "retry_limits": {"transport": 3}
}

而 reconcile_leases() 当前只检查 PID + creation identity 和 terminal event，并没有把 liveness expiry + Effective Progress expiry 纳入 lease occupied 判定。

测试也只验证了 process identity，并没有验证四项 conjunctive formula。

更关键的是，真实 bootstrap_review.py 仍保留：

CODEX_NO_PROGRESS_TIMEOUT_SECONDS = 900
SEGMENTED_ARTIFACT_VIEW_THRESHOLD_BYTES = ...
ARTIFACT_VIEW_SEGMENT_BYTES = ...

也就是说新的 runtime-policy / projection helper 目前还没有完全成为真实 Bootstrap 控制面的 authority。
