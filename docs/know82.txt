阻断 3：S4 coverage 可以由调用者任意编造

coverage-input.v1.json 不再直接提供权威 edges。Coverage gate 应从以下真实证据计算：

active acceptance manifest
→ semantic oracle covers_acceptance_ids
→ descriptor case binding
→ process receipt executed case
→ judge observation assertion
→ coverage edge

每个 edge 至少绑定：

{
  "acceptance_id": "...",
  "oracle_id": "...",
  "case_id": "...",
  "descriptor_hash": "...",
  "receipt_hash": "...",
  "observation_id": "...",
  "observation_hash": "..."
}

验证规则：

Acceptance ID 必须属于 active manifest；
oracle 必须明确覆盖该 Acceptance；
case 必须存在于 descriptor；
receipt 必须证明执行了同一个 case；
observation 必须来自该 receipt；
不允许未知 edge、缺失 edge 或孤立 observation；
many-to-many 可以重复覆盖，但最终 Acceptance 集必须 exact-cover。

必须增加 mutation tests：

替换 observation ID；
删除一个 Acceptance edge；
添加不存在的 Acceptance；
使用另一个 run 的 receipt；
修改 receipt 后仍沿用旧 hash。

全部必须 fail-closed。
