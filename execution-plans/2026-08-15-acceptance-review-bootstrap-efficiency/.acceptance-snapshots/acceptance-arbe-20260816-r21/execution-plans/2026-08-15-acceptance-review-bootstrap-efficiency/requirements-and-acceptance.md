## Observable Acceptance

- ARBE-A01: Missing, stale, or candidate-mismatched implementation-complete rejects admission.
- ARBE-A02: Baseline is a resolved commit; candidate mutation stales all dependent artifacts.
- ARBE-A03: Changed-set fixtures cover modified, added, deleted, renamed, and applicable untracked files.
- ARBE-A04: Manifest relationships independently recompute from the frozen baseline/current pair.
- ARBE-A05: Closure reaches the typed dependency fixed point with no sampling.
- ARBE-A06: Every inclusion/exclusion has a recomputable reason, source identity, and decision authority.
- ARBE-A07: Omission and wrong-exclusion mutations fail closed.
- ARBE-A08: Every required check executes its fixed real program and binds complete execution evidence.
- ARBE-A09: Deterministic failure launches zero semantic reviewers; stale reuse rejects.
- ARBE-A10: Required-check success deterministically selects `deterministic_only`; explicit admitted requests may select focused/full, and `manual_pause` remains non-authorizing.
- ARBE-A11: No authority/risk/supervision/control-plane signal or cost decision can auto-upgrade the default route; explicit request admission is required.
- ARBE-A12: Full conformance covers Blind Hunter, Edge Case Hunter, and Acceptance Auditor on identical frozen identities.
- ARBE-A13: Independent verifier runs only for gate-accepted P0/P1.
- ARBE-A14: In-budget authority is delivered unchanged and every Partial continues to Complete.
- ARBE-A15: Range mutation, source mutation, invalid boundary, or omitted applicable constraint rejects.
- ARBE-A16: Segment identity excludes attempt identity and binds every semantic input.
- ARBE-A17: Retry reuses the descriptor; repartition creates a successor descriptor.
- ARBE-A18: Child cannot traverse live repository or whole Artifact View.
- ARBE-A19: Executable/model/reasoning/environment inherit from the parent access proof.
- ARBE-A20: Heartbeat/stdout/polling do not refresh no-progress.
- ARBE-A21: Only validated terminal, evidence increment, or registered transition is Effective Progress.
- ARBE-A22: PID plus process creation identity prevents PID reuse.
- ARBE-A23: Lease occupancy is conjunctive and reconstructable from current evidence.
- ARBE-A24: Retry follows reconciliation, is family-bounded, and targets only failed segments.
- ARBE-A25: An explicit semantic-evidence cost decision binds closure bytes, segments, roles, attempts, retry exposure, comparison, route, launch, and policy.
- ARBE-A26: High cost can rebuild, repartition, pause, or formally override an explicit request; it cannot weaken deterministic coverage or lifecycle authority.
- ARBE-A27: Explicit Bootstrap import exact-matches request, candidate, closure, checks, gate, verifier, and receipt identities.
- ARBE-A28: Bootstrap artifacts carry authorizes=[]; only Acceptance publishes acceptance-passed.
- ARBE-A29: Shared primitive implements strict parse, canonical bytes, domain hash, path normalization, and identity validation.
- ARBE-A30: All mandatory consumers pass the same golden vectors and mutation corpus.
- ARBE-A31: Quick Dev removes production dependency on the 2026-07-15 execution-plan tools.
- ARBE-A32: Mandatory consumers reject legacy/current/wrong-domain/unknown-version cross-use without historical rewrite.
- ARBE-A33: Strict JSON rejects BOM, duplicates, floats, exponents, -0, overflow, invalid scalars, and coercion.
- ARBE-A34: Float-bearing Bootstrap owners adopt versioned integer/scaled/string projection; legacy remains verify-only.
- ARBE-A35: Historical failed runs remain abandoned, reusable=false, authorizes=[], with original attempt facts.
- ARBE-A36: 8-13 deterministic failure records reviewer_calls=0.
- ARBE-A37: Attempts do not exceed roles*segments + authorized retries + required verifier attempts.
- ARBE-A38: Frozen semantic corpus preserves route, blocker, ambiguity, omission, and detection parity.
- ARBE-A39: Transport failure and false-authorizing mutations never form semantic or lifecycle truth.
- ARBE-A40: Telemetry records actual closure, segments, attempts, retries, tokens, and wall time.
- ARBE-A41: Whole-directory remains default until M0/M1/M2 gates and counter-metrics pass.
- ARBE-A42: Required-check success defaults to `deterministic_only` without Bootstrap; only an Acceptance-owned explicit `--request-bootstrap=<profile>` record can select focused/full; `manual_pause` stops non-authorizing.
- ARBE-A43: An explicit Bootstrap request record and controlled command receipt bind baseline, candidate, consumer closure, required checks, requested profile, policy, and spec selection with `authorizes=[]`.
- ARBE-A44: Registered triggers, supervision, unattended operation, advisory risk suspicion, security/permission/data-corruption risk, lifecycle/authority control changes, and cost never auto-upgrade the default route.
- ARBE-A45: Web Sol text, screenshots, model verdicts, and copied booleans are advisory only and never form Acceptance authority.
- ARBE-A46: Default `deterministic_only` finalization requires current machine evidence only; explicitly requested focused/full routes require current finalized Bootstrap evidence; Acceptance alone publishes acceptance-passed.
