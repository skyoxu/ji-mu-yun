# 范围、来源与设计待决项

## 3. 术语与事实分类

- **Locator**：现有只返回定位、hash、来源和匹配信息的知识检索入口，不生成权威事实答案。
- **消费者身份**：受仓库策略约束的查询调用方；BMAD 身份需要正式声明，不能借用其他消费者。
- **来源身份**：区分已发布索引快照、当前 main、工作分支提交及未提交字节的定位与版本信息。
- **采纳结论**：读取有效来源后，对本次需求产生影响的判断及用途；不是完成证明。
- **治理**：既有强制校验、冻结、授权与证据流程；与本次轻量查询分别决定是否启用。
- **降级**：已识别的可用性或过期问题发生后，显式改用当前来源核查；不允许猜测必要事实。
- **fail-closed**：停止使用不可信结果并阻断受影响判断，直至按合同修正。
- **provenance**：仅承担溯源角色的输入；下游义务必须进入规范内容或适用 typed companion。
- **selection commitment**：现有外部来源选择绑定；其有效性不能代替正文完整性。
- **Acceptance**：既有正式验收 owner，查询与 PRD 内部审阅均不能代替它。

最新基线的分类结论如下：

| 分类 | 当前结论 |
| --- | --- |
| 已有且静态核实 | Locator、消费者策略/投影、VDD 治理分流、typed SPEC 外壳、官方配置覆盖点存在；不代表本次真实运行已验证 |
| 已有规划但未核实实现 | 历史目录和状态标记只作为线索，不据此声称已交付 |
| 拟新增 | BMAD 正式消费者、默认阶段查询、治理关闭时 VDD 查询及其真实消费验证 |
| 明确排除/延期 | Package B、S1/S2 游戏业务、沙箱重构及下文非目标 |
| 尚待核实 | 新接线实际行为、初次发布代次、Windows 路径/编码/子进程效果 |

PR #20 已拆分 jimuyun-spec／jimuyun-architecture 外壳，官方 BMAD 原生文件移出跟踪。当前仓库小型安装器只安装两外壳所需原生资源，不包含 PRD。Stock bmad-quick-dev 和旧 GDS/游戏设计兼容包已退役；quick-dev-tdd-adapter 仍保留。原始需求旧路径仅是历史证据，后续设计必须以最新 owner 为准。新定制必须外置，官方 BMAD 保持原样。


## 6. 范围、非目标与交付顺序

### 6.1 纳入范围

完整增量包含四类消费者的行为、最小身份/策略与结果适配、使用说明、必要 ADR/契约增量、针对性测试和可观察记录。不能只交配置文字就声称完成。

### 6.2 明确排除

- Package B 五个 Skill 的全面标准迁移；
- 重做 8-05、8-06、7-31；
- TC-D2/D4/D5/D6；
- Codex 内核、上下文压缩、自动新 thread、app-server/SDK；
- 新知识平台、向量库、通用 RAG、Memory/Miner、全仓索引重构或强制全量发布；
- Phase API/账号/生产节点/用户沙箱/Hosted 游戏功能；
- 自动 Bootstrap、总入口 Skill、内部 reviewer 平台或切片并行调度；
- 历史 plan/证据/代次改写；
- S1/S2 游戏业务和沙箱重构。

### 6.3 交付顺序与排期边界

产品阶段顺序保留为 PRD → SPEC → Architecture → 维护者显式请求 VDD → Quick Dev TDD → 正式 Acceptance 与逐阶段外部复核。当前执行在 Architecture 与本次预算 SPEC refresh 后暂停；后续授权以每阶段独立 A/B 审核和工作会话共同认可为条件。后续若实施 VDD 自身改造，使用稳定已验证工具链主持当前需求，候选只在隔离样例验证，并按现行 self-hosted 规则处理，不中途替换稳定工具链。

本需求在 Package A 后、Package B 前；验收合入 main 后新需求才能采用新查询能力。Package B 再做实际差异迁移，之后推进 7-31。游戏工作流重构正式 BMAD 规划建议采用本次合入后的能力，正式 VDD 建议等待 Package B 稳定，这些是版本安排。

**技术依赖不等于执行排期**：S2-06、S2-03A、S2-03B 可使用稳定工具链，表示本能力不是其新增技术运行依赖；是否现在开展、顺序如何由 Q1 决定，不授予并行执行权限。

## 来源角色与假设

PRD 和原始需求的全部 load-bearing 要求已进入本 SPEC 或规范 companions，故列为 provenance；附录继续提供当前基线源码定位及约束上下文；本次 finalized architecture 提供下游必须消费的 AD-1 至 AD-11。二者列为 adopted_companion，原字节只读。其“本轮”专指 PRD 时刻；安装、缓存、下载和审阅过程是历史证据，不是产品义务或当前授权。

A1：沿用单维护者内部能力表达，不添加 UI、市场指标或延迟目标。不能为命中率扩大权限，为完成率吞掉 blocked，或为记录数量加载全部历史。
